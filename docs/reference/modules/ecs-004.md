# `ecs-004` — iam:PassRole + ecs:RegisterTaskDefinition + ecs:RunTask

|  |  |
|---|---|
| ID | `ecs-004` |
| Category | new-passrole |
| Services | iam, ecs |
| Author | Seth Art |
| Aliases | `ecs-passrole`, `exploit/ecs_passrole` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ecs-004 |

Register an ECS task definition with a privileged role and run it on Fargate to execute attacker-controlled container commands with the role's permissions

## Required permissions

- `iam:PassRole` — Target role ARN must be in the Resource section
- `ecs:RegisterTaskDefinition` — Must have permission to register new task definitions
- `ecs:RunTask` — Must have permission to run tasks in the target cluster

## Additional permissions

- `ecs:DescribeServices` — Monitor service status and verify service creation
- `ecs:DescribeTasks` — Monitor task execution status
- `ecs:ListTasks` — List tasks in the cluster to get task ARN
- `ec2:DescribeVpcs` — Find VPCs for Fargate network configuration
- `ec2:DescribeSubnets` — Find subnets for Fargate network configuration
- `iam:ListRoles` — Discover available roles to pass

## Prerequisites

**Admin:**
- A role must exist that trusts ecs-tasks.amazonaws.com with administrative permissions

**Lateral:**
- A role must exist that trusts ecs-tasks.amazonaws.com

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to pass to the ECS task (must trust ecs-tasks.amazonaws.com) [auto] |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `REGION` | no | `us-east-1` | AWS region for ECS operations |
| `CLUSTER_NAME` | no | — | Name of an existing ECS cluster to run the task on (defaults to 'default' cluster) |
| `SUBNET_ID` | no | — | Subnet ID for Fargate network configuration (will auto-detect from default VPC if not specified) |
| `TASK_FAMILY` | no | — | ECS task definition family name (auto-generated if not specified) |
| `CONTAINER_IMAGE` | no | `public.ecr.aws/docker/library/alpine:latest` | Container image to use for the task |
| `CLEANUP` | no | `true` | Deregister the task definition after execution |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via ECS task container command
