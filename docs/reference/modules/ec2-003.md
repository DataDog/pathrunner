# `ec2-003` — ec2-instance-connect:SendSSHPublicKey

|  |  |
|---|---|
| ID | `ec2-003` |
| Category | existing-passrole |
| Services | iam, ec2 |
| Author | Seth Art |
| Aliases | `ec2-instanceconnect`, `exploit/ec2_instanceconnect` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ec2-003 |

Use ec2-instance-connect:SendSSHPublicKey to push a temporary SSH public key to a running EC2 instance, SSH in within the 60-second validity window, and extract the instance role's temporary credentials from IMDS. If the role has IAM write permissions, the stolen credentials can be used to elevate the starting principal to administrator.

## Required permissions

- `ec2-instance-connect:SendSSHPublicKey` — Target EC2 instance ID (instance must have EC2 Instance Connect enabled)

## Additional permissions

- `ec2:DescribeInstances` — Discover running instances with privileged roles
- `iam:GetInstanceProfile` — View instance profile to assess attached role permissions
- `iam:GetRole` — View role permissions before attempting exploitation

## Prerequisites

**Admin:**
- A running EC2 instance with an IAM instance profile that has administrative permissions
- The instance must have EC2 Instance Connect installed and the OS user must exist (ec2-user for Amazon Linux)
- The instance must have a public IP address reachable from the operator's machine
- SSH port 22 must be accessible from the operator's network

**Lateral:**
- A running EC2 instance with an IAM instance profile that has permissions useful for lateral movement
- The instance must have EC2 Instance Connect installed
- The instance must have a public IP address and SSH port accessible

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `INSTANCE_ID` | yes | — | Target EC2 instance ID (must have a public IP and EC2 Instance Connect enabled) |
| `REGION` | no | `us-east-1` | AWS region where the target instance runs |
| `EC2_USER` | no | `ec2-user` | OS user to authenticate as on the instance (ec2-user for Amazon Linux, ubuntu for Ubuntu) |
| `TARGET_USER` | no | — | IAM user name to attach AdministratorAccess to using the stolen instance role credentials (optional) |
| `SSH_TIMEOUT` | no | `10` | SSH connection timeout in seconds (must complete before the 60-second key expiry) |
