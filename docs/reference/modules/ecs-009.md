# `ecs-009` — iam:PassRole + ecs:StartTask

|  |  |
|---|---|
| ID | `ecs-009` |
| Category | new-passrole |
| Services | iam, ecs |
| Author | Seth Art |
| Aliases | `ecs-passrole-starttask`, `exploit/ecs_passrole_starttask` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ecs-009 |

Override an existing ECS task definition's container command and task role via ecs:StartTask --overrides on an EC2 container instance to execute code with the passed role's permissions

## Required permissions

- `iam:PassRole` — Must cover both the task role ARN (for the override) and the execution role ARN defined in the existing task definition
- `ecs:StartTask` — Must have permission to start tasks on an existing EC2 container instance in the target cluster

## Additional permissions

- `ecs:ListClusters` — Discover available ECS clusters
- `ecs:ListContainerInstances` — Retrieve container instance ARN needed for StartTask
- `ecs:ListTaskDefinitions` — Discover existing task definitions to exploit with overrides
- `ecs:DescribeTasks` — Monitor task execution status
- `iam:ListRoles` — Discover available roles to pass

## Prerequisites

**Admin:**
- An ECS cluster must exist with at least one registered EC2 container instance
- An existing task definition must be available in the cluster
- A role must exist that trusts ecs-tasks.amazonaws.com with administrative permissions

**Lateral:**
- An ECS cluster must exist with at least one registered EC2 container instance
- An existing task definition must be available in the cluster
- A role must exist that trusts ecs-tasks.amazonaws.com

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to pass as the task role override (must trust ecs-tasks.amazonaws.com) |
| `CLUSTER_NAME` | yes | — | ECS cluster name or ARN containing the EC2 container instance |
| `CONTAINER_INSTANCE_ARN` | yes | — | ARN of the EC2 container instance to start the task on |
| `TASK_DEFINITION` | yes | — | Existing task definition family name or ARN to override (no ecs:RegisterTaskDefinition needed) |
| `CONTAINER_NAME` | no | — | Name of the container in the task definition whose command will be overridden (auto-discovered from task definition if not set) |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `REGION` | no | `us-east-1` | AWS region for ECS operations |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via ECS task container command
