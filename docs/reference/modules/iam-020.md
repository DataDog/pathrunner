# `iam-020` — iam:CreatePolicyVersion + iam:UpdateAssumeRolePolicy

|  |  |
|---|---|
| ID | `iam-020` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-createpolicyversion-updateassumerolepolicy`, `exploit/iam_createpolicyversion_updateassumerolepolicy` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-020 |

Create a new version of a customer-managed policy with admin permissions and update the target role's trust policy to allow assumption. Does not require sts:AssumeRole permission beforehand.

## Required permissions

- `iam:CreatePolicyVersion` — Must have permission to create new versions of the target policy
- `iam:UpdateAssumeRolePolicy` — Must have permission to modify the trust policy of the target role

## Additional permissions

- `iam:ListRoles` — Discover available roles
- `iam:GetRole` — View role trust policies
- `iam:ListPolicyVersions` — List existing policy versions

## Prerequisites

**Admin:**
- A customer-managed policy must be attached to the target role

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `POLICY_ARN` | yes | — | ARN of the customer-managed policy to create a new version of |
| `TARGET_ROLE` | yes | — | Name of the IAM role to update trust policy for and assume |
| `REGION` | no | `us-east-1` | AWS region for IAM/STS operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after assuming the role |
