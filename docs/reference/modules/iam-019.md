# `iam-019` — iam:AttachRolePolicy + iam:UpdateAssumeRolePolicy

|  |  |
|---|---|
| ID | `iam-019` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-attachrolepolicy-updateassumerolepolicy`, `exploit/iam_attachrolepolicy_updateassumerolepolicy` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-019 |

Attach an admin managed policy to a target role and modify its trust policy to allow the attacker to assume it. Does NOT require pre-existing sts:AssumeRole permission — being explicitly named in the trust policy grants assumption ability.

## Required permissions

- `iam:AttachRolePolicy` — Must have permission to attach policies to the target role
- `iam:UpdateAssumeRolePolicy` — Must have permission to modify the trust policy of the target role

## Additional permissions

- `iam:ListRoles` — Discover available roles
- `iam:GetRole` — View role trust policies

## Prerequisites

**Admin:**
- An administrative managed policy must exist to attach (e.g., AdministratorAccess)

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_ROLE` | yes | — | Name of the IAM role to escalate and assume |
| `POLICY_ARN` | no | `arn:aws:iam::aws:policy/AdministratorAccess` | ARN of the managed policy to attach (defaults to AdministratorAccess) |
| `REGION` | no | `us-east-1` | AWS region for IAM/STS operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after assuming the role |
