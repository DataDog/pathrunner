# `iam-015` — iam:AttachUserPolicy + iam:CreateAccessKey

|  |  |
|---|---|
| ID | `iam-015` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-attachuserpolicy-createaccesskey`, `exploit/iam_attachuserpolicy_createaccesskey` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-015 |

Attach an administrative managed policy to a target user, then create access keys for that user to gain their elevated permissions. Requires both iam:AttachUserPolicy and iam:CreateAccessKey on the target user.

## Required permissions

- `iam:AttachUserPolicy` — Must have access to attach policies to the target user
- `iam:CreateAccessKey` — Must have permission to create access keys for the target user

## Additional permissions

- `iam:ListUsers` — Discover available users
- `iam:ListAccessKeys` — Check existing access key count

## Prerequisites

**Admin:**
- Target user must have fewer than 2 access keys (AWS limit)
- An AWS-managed or customer-managed policy with admin permissions must exist

**Lateral:**
- Target user must have fewer than 2 access keys (AWS limit)

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_USER` | yes | — | Target IAM username |
| `POLICY_ARN` | no | `arn:aws:iam::aws:policy/AdministratorAccess` | ARN of the managed policy to attach (defaults to AdministratorAccess) |
| `REGION` | no | `us-east-1` | AWS region for IAM/STS operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after successful key creation |
