# `ecs-002` — iam:PassRole + ecs:CreateCluster + ecs:RegisterTaskDefinition + ecs:RunTask

|  |  |
|---|---|
| ID | `ecs-002` |
| Category | new-passrole |
| Services | iam, ecs |
| Author | Seth Art |
| Aliases | `ecs-passrole-createcluster`, `exploit/ecs_passrole_createcluster` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ecs-002 |

Create an ECS cluster, register a task definition with a privileged role, and run it on Fargate to execute attacker-controlled container commands with the role's permissions

## Required permissions

- `iam:PassRole` — Target role ARN must trust ecs-tasks.amazonaws.com
- `ecs:CreateCluster` — Must be able to create ECS clusters
- `ecs:RegisterTaskDefinition` — Must be able to register new task definitions
- `ecs:RunTask` — Must be able to run tasks on the cluster

## Additional permissions

- `ec2:DescribeVpcs` — Find VPCs for Fargate network configuration
- `ec2:DescribeSubnets` — Find subnets for Fargate network configuration
- `ecs:DescribeTasks` — Monitor task execution status
- `iam:ListRoles` — Discover available roles to pass

## Prerequisites

**Admin:**
- A role must exist that trusts ecs-tasks.amazonaws.com with administrative permissions

**Lateral:**
- A role must exist that trusts ecs-tasks.amazonaws.com

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to pass to the ECS task (must trust ecs-tasks.amazonaws.com) |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `REGION` | no | `us-east-1` | AWS region for ECS cluster and task deployment |
| `CLUSTER_NAME` | no | — | Name for the new ECS cluster to create |
| `SUBNET_ID` | no | — | Subnet ID for Fargate network configuration (will auto-detect from default VPC if not specified) |
| `TASK_FAMILY` | no | — | ECS task definition family name |
| `CONTAINER_IMAGE` | no | `amazon/aws-cli:latest` | Container image to use for the task |
| `CLEANUP` | no | `true` | Delete cluster and deregister task definition after execution |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via ECS task container command
