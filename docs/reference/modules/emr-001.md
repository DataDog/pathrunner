# `emr-001` — iam:PassRole + elasticmapreduce:RunJobFlow

|  |  |
|---|---|
| ID | `emr-001` |
| Category | new-passrole |
| Services | iam, emr |
| Author | Seth Art |
| Aliases | `emr-passrole`, `exploit/emr_passrole` |
| pathfinding.cloud | https://pathfinding.cloud/paths/emr-001 |

Create an EMR cluster with a privileged IAM instance profile as the JobFlowRole. An EMR step using command-runner.jar executes on the master node, which has access to the instance profile credentials via IMDS, and calls iam:AttachUserPolicy to escalate the starting principal to administrative access. The cluster auto-terminates after the step.

## Required permissions

- `iam:PassRole` — Must be able to pass both the EC2 instance profile role and the EMR service role
- `elasticmapreduce:RunJobFlow`

## Additional permissions

- `elasticmapreduce:DescribeCluster` — Poll cluster state to confirm execution
- `elasticmapreduce:ListSteps` — Verify step execution status
- `iam:ListAttachedUserPolicies` — Verify privilege escalation success

## Prerequisites

**Admin:**
- IAM role that can be used as an EC2 instance profile (trusts ec2.amazonaws.com) with administrative permissions
- IAM role that can serve as the EMR service role (trusts elasticmapreduce.amazonaws.com)
- The AWSServiceRoleForEMRCleanup service-linked role must exist in the account

**Lateral:**
- A role that can be used as an EC2 instance profile with elevated permissions
- A role that can serve as the EMR service role

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `INSTANCE_PROFILE` | yes | — | Admin IAM instance profile name to pass as the EMR JobFlowRole (the EC2 master node assumes this role) |
| `SERVICE_ROLE` | yes | — | EMR service role name to pass as the ServiceRole (trusts elasticmapreduce.amazonaws.com) |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `TARGET_ARN` | no | — | IAM user or role name/ARN to escalate (auto-detected from current identity if not set) |
| `REGION` | no | `us-east-1` | AWS region for the EMR cluster |
| `RELEASE_LABEL` | no | `emr-7.0.0` | EMR release label |
| `INSTANCE_TYPE` | no | `m5.xlarge` | EC2 instance type for the master node |
| `CLUSTER_NAME` | no | — | Name for the EMR cluster |
| `CLEANUP` | no | `false` | Terminate cluster if it is still running after execution (clusters auto-terminate via --auto-terminate) |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via an EMR step command
