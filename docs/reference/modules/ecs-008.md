# `ecs-008` — iam:PassRole + ecs:RunTask

|  |  |
|---|---|
| ID | `ecs-008` |
| Category | new-passrole |
| Services | iam, ecs |
| Author | Seth Art |
| Aliases | `ecs-passrole-runtask`, `exploit/ecs_passrole_runtask` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ecs-008 |

Override an existing ECS task definition's container command and task role at runtime using the --overrides parameter of ecs:RunTask — no ecs:RegisterTaskDefinition required

## Required permissions

- `iam:PassRole` — Must cover both the task role ARN (for the taskRoleArn override) and the execution role ARN in the existing task definition
- `ecs:RunTask` — Must have permission to run tasks in the target cluster

## Additional permissions

- `ecs:ListClusters` — Discover available ECS clusters
- `ecs:ListTaskDefinitions` — Discover existing task definitions to exploit with overrides
- `ecs:DescribeTasks` — Monitor task execution status
- `ec2:DescribeVpcs` — Find VPCs for Fargate network configuration
- `ec2:DescribeSubnets` — Find subnets for Fargate network configuration
- `iam:ListRoles` — Discover available roles to pass

## Prerequisites

**Admin:**
- An ECS cluster must exist in the account
- An existing task definition must be available (no ecs:RegisterTaskDefinition required)
- A role must exist that trusts ecs-tasks.amazonaws.com with administrative permissions
- A subnet must be available for Fargate launch type network configuration

**Lateral:**
- An ECS cluster must exist in the account
- An existing task definition must be available
- A role must exist that trusts ecs-tasks.amazonaws.com
- A subnet must be available for Fargate launch type network configuration

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to pass as taskRoleArn override (must trust ecs-tasks.amazonaws.com) |
| `CLUSTER_NAME` | yes | — | ECS cluster name or ARN to run the task on |
| `TASK_DEFINITION` | yes | — | Existing ECS task definition family or ARN to exploit via --overrides |
| `CONTAINER_NAME` | no | `app` | Name of the container in the existing task definition to override (default: first container) |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `REGION` | no | `us-east-1` | AWS region for ECS operations |
| `SUBNET_ID` | no | — | Subnet ID for Fargate network configuration (will auto-detect from default VPC if not specified) |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via ECS task container command
