# `iam-011` — iam:PutGroupPolicy

|  |  |
|---|---|
| ID | `iam-011` |
| Category | self-escalation |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-putgrouppolicy`, `exploit/iam_putgrouppolicy` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-011 |

A principal with iam:PutGroupPolicy can attach inline policies to any group they have this permission on. This is often abused to grant additional permissions by attaching an inline admin policy to a group the caller is a member of.

## Required permissions

- `iam:PutGroupPolicy` — Target group must be in Resource section; for self-escalation, must be a member of that group

## Prerequisites

**Admin:**
- Principal must be a user (not a role)
- Principal must be a member of the target group

**Lateral:**
- Principal must be a user (not a role)
- Principal must be a member of the target group

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `GROUP_NAME` | yes | — | IAM group name to add the inline policy to (must be a group the caller belongs to) |
| `POLICY_NAME` | no | `pathrunner-admin` | Name for the inline policy to add |
| `REGION` | no | `us-east-1` | AWS region for IAM operations |
| `VERIFY` | no | `true` | Verify escalation by calling iam:ListUsers after (true/false) |
