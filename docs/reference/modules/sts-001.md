# `sts-001` — sts:AssumeRole

|  |  |
|---|---|
| ID | `sts-001` |
| Category | principal-access |
| Services | sts |
| Author | Seth Art |
| Aliases | `sts-assume-role`, `exploit/sts_assume_role` |
| pathfinding.cloud | https://pathfinding.cloud/paths/sts-001 |

Assume an IAM role using current credentials and switch to the new identity

## Required permissions

- `sts:AssumeRole` — Target role ARN

## Prerequisites

**Admin:**
- Target role with trust policy allowing the calling principal

**Lateral:**
- Principal with sts:AssumeRole on the target role

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to assume |
| `SESSION_NAME` | no | `pathrunner-session` | Session name for the assumed role |
| `EXTERNAL_ID` | no | — | External ID if required by the role's trust policy |
| `DURATION` | no | `3600` | Session duration in seconds (900-43200, default 3600) |
| `REGION` | no | `us-east-1` | AWS region for STS operations |
| `IDENTITY_NAME` | no | — | Name for the new identity (auto-generated if not provided) |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after successful assumption |
