# `iam-021` — iam:PutRolePolicy + iam:UpdateAssumeRolePolicy

|  |  |
|---|---|
| ID | `iam-021` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-putrolepolicy-updateassumerolepolicy`, `exploit/iam_putrolepolicy_updateassumerolepolicy` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-021 |

Add an inline policy with admin permissions to a target role and modify its trust policy to allow assumption. When a principal is explicitly named in a trust policy, they can assume the role without separate sts:AssumeRole permissions.

## Required permissions

- `iam:PutRolePolicy` — Must have permission to add inline policies to the target role
- `iam:UpdateAssumeRolePolicy` — Must have permission to modify the trust policy of the target role

## Additional permissions

- `iam:ListRoles` — Discover available roles
- `iam:GetRole` — View role trust policies

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_ROLE` | yes | — | Name of the IAM role to escalate and assume |
| `POLICY_NAME` | no | `pathrunner-admin` | Name for the inline policy to add |
| `REGION` | no | `us-east-1` | AWS region for IAM/STS operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after assuming the role |
