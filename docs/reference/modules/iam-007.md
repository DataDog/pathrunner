# `iam-007` — iam:PutUserPolicy

|  |  |
|---|---|
| ID | `iam-007` |
| Category | self-escalation |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-putuserpolicy`, `exploit/iam_putuserpolicy` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-007 |

A principal with iam:PutUserPolicy can attach inline policies to any user they have this permission on. This is frequently exploited for self-escalation by granting the caller's own user full administrative access.

## Required permissions

- `iam:PutUserPolicy` — Target user must be in Resource section; for self-escalation, must have permission on own user

## Prerequisites

**Admin:**
- Principal must be a user (not a role)
- User must have iam:PutUserPolicy permission on itself

**Lateral:**
- Principal must be a user (not a role)
- User must have iam:PutUserPolicy permission on itself
