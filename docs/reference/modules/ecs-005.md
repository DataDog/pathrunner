# `ecs-005` — iam:PassRole + ecs:RegisterTaskDefinition + ecs:StartTask

|  |  |
|---|---|
| ID | `ecs-005` |
| Category | new-passrole |
| Services | iam, ecs |
| Author | Seth Art |
| Aliases | `ecs-passrole-registertaskdefinition-starttask`, `exploit/ecs_registertaskdefinition_starttask` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ecs-005 |

Register an ECS task definition with a privileged role and start it on an EC2 container instance to execute attacker-controlled container commands with the role's permissions

## Required permissions

- `iam:PassRole` — Target role ARN must be in the Resource section
- `ecs:RegisterTaskDefinition` — Must have permission to register new task definitions
- `ecs:StartTask` — Must have permission to start tasks on an EC2 container instance

## Additional permissions

- `ecs:ListClusters` — Discover available ECS clusters
- `ecs:ListContainerInstances` — Discover EC2 container instances in the cluster
- `ecs:DescribeTasks` — Monitor task execution status
- `iam:ListRoles` — Discover available roles to pass

## Prerequisites

**Admin:**
- An ECS cluster must exist with at least one registered EC2 container instance
- A role must exist that trusts ecs-tasks.amazonaws.com with administrative permissions

**Lateral:**
- An ECS cluster must exist with at least one registered EC2 container instance
- A role must exist that trusts ecs-tasks.amazonaws.com

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to pass to the ECS task (must trust ecs-tasks.amazonaws.com) |
| `CLUSTER_NAME` | yes | — | ECS cluster name or ARN containing the EC2 container instance |
| `CONTAINER_INSTANCE_ARN` | yes | — | ARN of the EC2 container instance to start the task on |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `REGION` | no | `us-east-1` | AWS region for ECS operations |
| `TASK_FAMILY` | no | — | ECS task definition family name |
| `CONTAINER_IMAGE` | no | `amazon/aws-cli:latest` | Container image to use for the task |
| `CLEANUP` | no | `true` | Deregister task definition after execution |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via ECS task container command
