# `iam-002` — iam:CreateAccessKey

|  |  |
|---|---|
| ID | `iam-002` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-createaccesskey`, `exploit/iam_createaccesskey` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-002 |

Create access keys for a target IAM user to gain their permissions. Anyone with iam:CreateAccessKey on a target user can generate new credentials and authenticate as that user.

## Required permissions

- `iam:CreateAccessKey` — Target IAM user must be in the Resource section

## Additional permissions

- `iam:ListUsers` — Helpful for discovering target users
- `iam:GetUser` — Useful for viewing user details
- `iam:ListAttachedUserPolicies` — Identify users with admin permissions

## Prerequisites

**Admin:**
- Target user must have fewer than 2 access keys already
- Target user must have administrative permissions (e.g., AdministratorAccess)

**Lateral:**
- Target user must have fewer than 2 access keys already

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_USER` | yes | — | Username of the target IAM user to create access keys for |
| `REGION` | no | `us-east-1` | AWS region for IAM/STS operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after successful key creation |
