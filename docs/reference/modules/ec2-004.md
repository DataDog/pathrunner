# `ec2-004` — iam:PassRole + ec2:RequestSpotInstances

|  |  |
|---|---|
| ID | `ec2-004` |
| Category | new-passrole |
| Services | iam, ec2 |
| Author | Seth Art |
| Aliases | `ec2-passrole-spot`, `exploit/ec2_passrole_requestspotinstances` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ec2-004 |

Request an EC2 spot instance with a privileged IAM instance profile and inject malicious user-data that runs with the role's credentials on launch. Unlike ec2:RunInstances this attack vector uses the spot market API, which may be overlooked in permission reviews.

## Required permissions

- `iam:PassRole` — Pass the target instance profile role to the spot instance
- `ec2:RequestSpotInstances` — Submit the spot instance request

## Additional permissions

- `ec2:DescribeImages` — Auto-detect current Amazon Linux 2023 AMI
- `ec2:DescribeVpcs` — Auto-detect default VPC
- `ec2:DescribeSubnets` — Auto-detect subnet
- `ec2:DescribeSpotInstanceRequests` — Poll spot request status until fulfilled
- `ec2:DescribeInstances` — Verify instance launch

## Prerequisites

**Admin:**
- IAM instance profile with administrative permissions must exist
- VPC with at least one subnet for instance placement

**Lateral:**
- Principal with iam:PassRole scoped to the target instance profile role
- Principal with ec2:RequestSpotInstances

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `INSTANCE_PROFILE` | yes | — | Target IAM instance profile name to pass to the spot instance |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy, exfil/https, revshell/tls) |
| `REGION` | no | `us-east-1` | AWS region for the spot instance request |
| `AMI_ID` | no | — | AMI ID for the spot instance (auto-detects Amazon Linux 2023 if not specified) |
| `INSTANCE_TYPE` | no | `t3.micro` | EC2 instance type for the spot request |
| `SPOT_PRICE` | no | `0.05` | Maximum spot price (USD per hour) |
| `SUBNET_ID` | no | — | Subnet ID for instance placement (uses default VPC if not specified) |
| `SPOT_WAIT_TIMEOUT` | no | `180` | Seconds to wait for spot request fulfillment (demo calibrated: 180) |
| `CLEANUP` | no | `false` | Cancel spot request and terminate instance after execution (requires ec2:CancelSpotInstanceRequests and ec2:TerminateInstances; starting user typically lacks these) |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via EC2 user-data
- `backdoor/create-access-key` — Create access keys for an existing IAM user via EC2 user-data
- `backdoor/create-role` — Create an IAM role with administrator privileges and custom trust policy via EC2 user-data
- `backdoor/create-user` — Create an IAM user with administrator privileges and optional console/programmatic access via EC2 user-data
- `backdoor/update-role-trust` — Append a trust policy statement to an existing IAM role via EC2 user-data
- `exfil/https` — Exfiltrate instance role credentials to an attacker-controlled HTTPS endpoint via EC2 user-data
- `exfil/s3` — Exfiltrate EC2 instance role credentials to an attacker-controlled S3 bucket via user-data
- `revshell/tls` — Establish a TLS-encrypted reverse shell via EC2 user-data
