# `iam-017` — iam:PutRolePolicy + sts:AssumeRole

|  |  |
|---|---|

| Category | principal-access |

| Author | Seth Art |

Add an inline policy with admin permissions to a target role, then assume that role. The target role must have a trust policy allowing assumption. Inline policies are embedded directly in IAM roles and are often overlooked in security reviews.

## Required permissions

- `iam:PutRolePolicy` — Must have permission on the target role ARN
- `sts:AssumeRole` — Must have permission to assume the target role

## Additional permissions

- `iam:ListRoles` — Discover available roles
- `iam:GetRole` — View role trust policies

## Prerequisites

**Admin:**
- Target role's trust policy must allow your principal to assume it

**Lateral:**
- Target role's trust policy must allow your principal to assume it

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_ROLE` | yes | — | ARN of the IAM role to escalate and assume |
| `POLICY_NAME` | no | `pathrunner-admin` | Name for the inline policy to add |
| `REGION` | no | `us-east-1` | AWS region for IAM/STS operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after assuming the role |
