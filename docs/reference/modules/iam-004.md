# `iam-004` — iam:CreateLoginProfile

|  |  |
|---|---|
| ID | `iam-004` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-createloginprofile`, `exploit/iam_createloginprofile` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-004 |

Create a console login profile for a target IAM user to gain access to their permissions via the AWS Console

## Required permissions

- `iam:CreateLoginProfile` — Target IAM user must be in the Resource section

## Additional permissions

- `iam:ListUsers` — Helpful for discovering target users
- `iam:GetUser` — Useful for viewing user details
- `iam:GetLoginProfile` — Check if user already has login profile

## Prerequisites

**Admin:**
- Target user must NOT currently have a login profile
- Target user must have administrative permissions (e.g., AdministratorAccess)

**Lateral:**
- Target user must NOT currently have a login profile

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_USER` | yes | — | Target IAM user name to create login profile for |
| `PASSWORD` | no | — | Password for the login profile (auto-generated if not provided) |
| `NO_PASSWORD_RESET` | no | `true` | Skip password reset requirement on first login (true/false) |
| `REGION` | no | `us-east-1` | AWS region for IAM operations |
| `ADMIN_ROLE_ARN` | no | — | ARN of a role to assume before calling iam:CreateLoginProfile (required when starting as a user without direct CreateLoginProfile permission) |
