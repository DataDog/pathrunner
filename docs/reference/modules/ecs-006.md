# `ecs-006` — ecs:ExecuteCommand + ecs:DescribeTasks

|  |  |
|---|---|

| Category | existing-passrole |

| Author | Seth Art |
| Aliases | `ecs-executecommand`, `exploit/ecs_executecommand` |

Execute a command in a running ECS task via ECS Exec to retrieve the task role's temporary credentials from the container metadata endpoint

## Required permissions

- `ecs:ExecuteCommand` — Must have permission on ECS tasks in clusters with ECS Exec enabled
- `ecs:DescribeTasks` — Required by the AWS CLI to retrieve the container runtime ID for establishing the SSM session

## Additional permissions

- `ecs:ListClusters` — Helpful for discovering ECS clusters in the account
- `ecs:ListTasks` — Helpful for discovering task ARNs in the target cluster
- `ecs:DescribeTaskDefinition` — Useful for viewing the task definition to discover the task role ARN

## Prerequisites

**Admin:**
- An ECS service must have ECS Exec explicitly enabled (enable_execute_command = true)
- The service must have at least one running task with an administrative task role
- The ECS Exec agent (SSM agent) must be running and healthy in the container
- The AWS Systems Manager Session Manager plugin must be installed locally

**Lateral:**
- An ECS service must have ECS Exec explicitly enabled (enable_execute_command = true)
- The service must have at least one running task with a privileged task role
- The ECS Exec agent (SSM agent) must be running and healthy in the container
- The AWS Systems Manager Session Manager plugin must be installed locally

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `CLUSTER_NAME` | yes | — | ECS cluster name or ARN containing the target task |
| `TASK_ARN` | no | — | Target ECS task ARN to execute command on (auto-discovered if not set) |
| `CONTAINER_NAME` | no | — | Container name within the task (auto-detected from task definition if not set) |
| `REGION` | no | `us-east-1` | AWS region |
