# `ecs-003` — iam:PassRole + ecs:RegisterTaskDefinition + ecs:CreateService

|  |  |
|---|---|
| ID | `ecs-003` |
| Category | new-passrole |
| Services | iam, ecs |
| Author | Seth Art |
| Aliases | `ecs-passrole-createservice`, `exploit/ecs_passrole_createservice` |
| pathfinding.cloud | https://pathfinding.cloud/paths/ecs-003 |

Register an ECS task definition with a privileged role and launch it as a Fargate service to execute code with the role's permissions

## Required permissions

- `iam:PassRole` — Target role ARN that trusts ecs-tasks.amazonaws.com
- `ecs:RegisterTaskDefinition`
- `ecs:CreateService`

## Additional permissions

- `ec2:DescribeVpcs` — Auto-detect default VPC
- `ec2:DescribeSubnets` — Auto-detect subnet for Fargate
- `ecs:ListClusters` — Discover available ECS clusters
- `ecs:DescribeServices` — Monitor service status
- `ecs:DescribeTasks` — Monitor task execution
- `ecs:ListTasks` — List tasks in service
- `iam:ListRoles` — Discover passable roles

## Prerequisites

**Admin:**
- An ECS cluster must exist in the account
- A role must exist that trusts ecs-tasks.amazonaws.com with desired permissions

**Lateral:**
- Principal with iam:PassRole, ecs:RegisterTaskDefinition, and ecs:CreateService

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `ROLE_ARN` | yes | — | Target IAM role ARN to pass to the ECS task (must trust ecs-tasks.amazonaws.com) |
| `CLUSTER_ARN` | yes | — | ECS cluster ARN or name to create the service on |
| `PAYLOAD` | yes | — | Payload type (backdoor/attach-policy) |
| `REGION` | no | `us-east-1` | AWS region for ECS deployment |
| `SUBNET_ID` | no | — | Subnet ID for Fargate task networking (auto-detects default VPC if not set) |
| `TASK_FAMILY` | no | — | ECS task definition family name |
| `SERVICE_NAME` | no | — | ECS service name |
| `CONTAINER_IMAGE` | no | `amazon/aws-cli:latest` | Container image for the task (default: amazon/aws-cli:latest) |
| `CLEANUP` | no | `true` | Clean up ECS service and task definition after execution |

## Compatible payloads

- `backdoor/attach-policy` — Attach AdministratorAccess policy to an IAM user or role via ECS task container command
