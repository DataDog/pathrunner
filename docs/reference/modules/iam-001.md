# `iam-001` — iam:CreatePolicyVersion

|  |  |
|---|---|
| ID | `iam-001` |
| Category | self-escalation |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-createpolicyversion`, `exploit/iam_create_policy_version` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-001 |

Create a new version of an attached IAM policy with administrative permissions and set it as the default version, effectively granting the caller full admin access

## Required permissions

- `iam:CreatePolicyVersion` — Policy ARN must be attached to the actor; for self-escalation on a role, must have permission on own role's policy

## Additional permissions

- `iam:ListPolicyVersions` — List existing policy versions
- `iam:GetPolicyVersion` — View content of policy versions
- `sts:AssumeRole` — Required when starting as a user to assume the target role

## Prerequisites

**Admin:**
- Policy must already be attached to the actor's role
- If starting as a user, must be able to assume the target role

**Lateral:**
- Policy must already be attached to the actor's role
- If starting as a user, must be able to assume the target role

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `POLICY_ARN` | yes | — | ARN of the IAM policy to create a new version of (must be attached to caller) |
| `ROLE_ARN` | no | — | ARN of the role to escalate (auto-detected from caller if caller is a role; required when caller is a user) |
| `REGION` | no | `us-east-1` | AWS region for IAM operations |
| `POLICY_DOCUMENT` | no | — | Custom policy document JSON (defaults to full admin *:*) |
| `VERIFY` | no | `true` | Verify escalation by calling iam:ListUsers after (true/false) |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after assuming role (true/false) |
