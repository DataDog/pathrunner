# `iam-006` — iam:UpdateLoginProfile

|  |  |
|---|---|
| ID | `iam-006` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-updateloginprofile`, `exploit/iam_updateloginprofile` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-006 |

Anyone with iam:UpdateLoginProfile can change the password of any user they have this permission on. This is often abused to gain access to another principal's account and their associated permissions via the AWS Console.

## Required permissions

- `iam:UpdateLoginProfile` — Target IAM user must be in Resource section

## Additional permissions

- `iam:ListUsers` — Discover target users
- `iam:GetUser` — View user details

## Prerequisites

**Admin:**
- Target user must already have a login profile (password)
- Target user must have administrative permissions (e.g., AdministratorAccess)

**Lateral:**
- Target user must already have a login profile (password)

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_USER` | yes | — | Target IAM user name to update login profile for |
| `PASSWORD` | no | — | New password for the login profile (auto-generated if not provided) |
| `NO_PASSWORD_RESET` | no | `true` | Skip password reset requirement on first login (true/false) |
| `REGION` | no | `us-east-1` | AWS region for IAM operations |
