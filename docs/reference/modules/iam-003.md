# `iam-003` — iam:CreateAccessKey + iam:DeleteAccessKey

|  |  |
|---|---|
| ID | `iam-003` |
| Category | principal-access |
| Services | iam |
| Author | Seth Art |
| Aliases | `iam-deleteaccesskey-createaccesskey`, `exploit/iam_deleteaccesskey_createaccesskey` |
| pathfinding.cloud | https://pathfinding.cloud/paths/iam-003 |

Delete an existing access key and create a new one for a target user, bypassing the 2-key AWS limit to gain access to the target user's permissions

## Required permissions

- `iam:CreateAccessKey` — Target IAM user must be in the Resource section
- `iam:DeleteAccessKey` — Target IAM user must be in the Resource section

## Additional permissions

- `iam:ListAccessKeys` — List existing access keys to identify which one to delete
- `iam:ListUsers` — Discover target users
- `iam:GetUser` — View user details

## Prerequisites

**Admin:**
- Target user has 2 access keys (maximum allowed)
- Target user must have administrative permissions (e.g., AdministratorAccess)

**Lateral:**
- Target user has 2 access keys (maximum allowed)

## Options

| Name | Required | Default | Description |
|------|----------|---------|-------------|
| `TARGET_USER` | yes | — | Target IAM username to create access keys for |
| `DELETE_KEY_ID` | no | — | Specific access key ID to delete (auto-detected if not set) |
| `REGION` | no | `us-east-1` | AWS region for IAM operations |
| `AUTO_SWITCH` | no | `true` | Automatically switch to new identity after successful key creation |
