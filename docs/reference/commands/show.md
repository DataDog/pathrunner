# `pathrunner show`

Show module options or information

## Usage

```
pathrunner show
```

## Subcommands

### `pathrunner show info`

Show detailed path metadata for current module

```
pathrunner show info
```

### `pathrunner show modules`

List all available modules

```
pathrunner show modules
```

### `pathrunner show options`

Show current module options

```
pathrunner show options
```

### `pathrunner show payload`

Show payload information

```
pathrunner show payload
```

#### `pathrunner show payload options`

Show options for current payload

```
pathrunner show payload options
```

### `pathrunner show payloads`

List payloads for current module

```
pathrunner show payloads
```
