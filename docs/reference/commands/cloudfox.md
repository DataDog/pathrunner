# `pathrunner cloudfox`

Import cloudfox output data

Import AWS resource data from cloudfox output directories

## Usage

```
pathrunner cloudfox
```

## Subcommands

### `pathrunner cloudfox import`

Import cloudfox output data

```
pathrunner cloudfox import [flags]
```

| Flag | Short | Type | Default | Description |
|------|-------|------|---------|-------------|
| `--path` |  | string | — | Cloudfox output directory path |
