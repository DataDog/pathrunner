# `pathrunner payloads`

List available payloads

## Usage

```
pathrunner payloads [flags]
```

| Flag | Short | Type | Default | Description |
|------|-------|------|---------|-------------|
| `--all` |  | bool | `false` | List payloads for all modules |

## Subcommands

### `pathrunner payloads list`

List all available payloads

```
pathrunner payloads list [flags]
```

| Flag | Short | Type | Default | Description |
|------|-------|------|---------|-------------|
| `--all` |  | bool | `false` | List payloads for all modules |
