# `pathrunner sessions`

Manage reverse shell sessions

## Usage

```
pathrunner sessions
```

## Subcommands

### `pathrunner sessions interact`

Interact with a session

```
pathrunner sessions interact [id]
```

### `pathrunner sessions kill`

Kill a session

```
pathrunner sessions kill [id]
```

### `pathrunner sessions list`

List all shell sessions

```
pathrunner sessions list
```
